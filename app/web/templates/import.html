What happens after you upload

  1. The file format is detected and checked for safety.
  2. Transactions are read out and put into one standard form.
  3. Rows already imported before are skipped, so nothing is counted twice.
  4. Each credit is classified using several signals, not just one word.
  5. Each payment is matched to the salary month it belongs to.
  6. Expected, sanctioned and received amounts are compared.
  7. Anything uncertain is shown for you to confirm — never guessed silently.

Any row that cannot be read is listed for you afterwards. Nothing is thrown away quietly.
